# Amey Samarth — Data Analyst Portfolio

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript. Includes a profile photo, experience, featured analytics projects, skills, social links, and a light/dark theme toggle.

## Run locally
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, `script.js`, and `profile.jpg` in the same folder.
3. Double-click `index.html` to open it in a browser.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. For a project repository named `Portfolio`, the URL is typically `https://ameyasamarth04.github.io/Portfolio/`.
